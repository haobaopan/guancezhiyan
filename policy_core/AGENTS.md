# policy_core 修改导航

- 本包由旧单体拆分而来。先读 `../docs/源码导航与模块拆分_V1.md`，按职责检索，不要编辑 `../backups/` 中的历史文件。
- 登录注册、模型设置和持久记忆 UI 位于 `../app/web/`；本包 `web/` 是旧版 8765 页面的资源。
- `runtime.py` 负责组装和实例状态；各 Mixin 通过 `self` 调用跨职责服务。不要恢复共享可变全局变量、动态 `exec`、源码拼接或引入循环导入。
- V2 经 `../app/legacy.py` 注入只读公共库和请求客户端。导入包不能自动加载 `.env`，不能把用户 key 放入系统环境。
- 公共知识库、真实原件和运行数据不是源码重构目标。不要为了验证直接写入真实知识库。
- 用户要求当前开发阶段暂缓耗时自检；在最终代码敲定前只进行必要的基础语法和导入确认，完整回归由用户之后安排。
